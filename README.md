## 线上页面仍显示“兜底名单”的排查说明

如果 DeepAlpha 页面提示“成分股动态获取失败，当前为兜底名单”，说明前端用于生成「今日机构建仓榜」的成分股动态接口没有拿到可用数据，页面因此回退到内置兜底列表。

本仓库当前只包含研究 Notebook（`yfinance.ipynb`）和项目说明，没有包含 `deepalpha.club` 线上站点的前端、后端或部署配置代码。因此，仅修改本仓库无法直接改变线上页面的数据来源或兜底逻辑。

要彻底修复线上仍使用兜底的问题，请在承载线上站点的代码仓库中检查以下位置：

1. **成分股动态接口**：确认接口返回 HTTP 200，且响应中包含非空的股票列表。
2. **接口鉴权与环境变量**：确认生产环境的 API Key、Base URL、代理地址、CORS 白名单均配置正确。
3. **前端解析逻辑**：确认接口字段名与前端读取字段一致，避免接口成功但解析为空。
4. **生产部署版本**：确认最新修复已经构建并发布到 `deepalpha.club`，而不是只在本地或预览环境生效。
5. **兜底提示条件**：当真实数据为空或请求失败时，应展示明确错误原因，便于区分“接口失败”“数据为空”和“字段解析失败”。

建议将线上站点源码加入本仓库，或提供对应仓库路径后再进行代码级修复。
